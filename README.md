# DevShop - E-Commerce Website

## Project Objective
The objective of this project is to build an e-commerce website using a feature-branch Git workflow. Each feature is developed on a separate branch and merged into `main` using Pull Requests on GitHub.

## Technologies Used
* HTML
* CSS
* JavaScript
* Git & GitHub

## Git Workflow
1. Created feature branches (`feature-home`, `feature-products`, `feature-about`, `feature-contact`, `feature-login`, `feature-ui`, `feature-header`).
2. Developed changes and committed locally.
3. Pushed feature branches to GitHub.
4. Created and merged Pull Requests into `main`.
5. Pulled the updated `main` branch locally and deleted merged local branches.
6. Triggered and resolved a merge conflict on `index.html`.
